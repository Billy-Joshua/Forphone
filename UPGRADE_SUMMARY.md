In `styles.css`, find and replace:
- `#00ffcc` → your cyan color
- `#ff00ff` → your pink color

### Add Products:
In `script-professional.js`, add to the `products` array:
```javascript

  id: 17, 
  name: 'Samsung Galaxy S27', 
  price: 1499000,
  storage: '1TB',
```

## ❓ FAQ

**Q: Do I need to code anything myself?**
A: No! It's ready to deploy as-is. Just add images and contact info.

**Q: Where do I add images?**
A: In the `images/` subfolder. Filenames must match product names exactly.

**Q: How much does it cost to deploy?**
A: Netlify and Vercel are FREE for small sites. Traditional hosting ~$5-20/month.

**Q: Can I modify the code later?**
A: Yes! All code is well-commented and easy to understand.

**Q: How do I get paid from orders?**
A: Currently uses WhatsApp for confirmation, then you handle payments via Mobile Money manually. Consider adding Stripe/PayPal for automation.

**Q: What if images don't load?**
A: The app has fallback SVG placeholders - visitors can still see product names and prices. Add real images for best results.

**Q: Is it secure for real payments?**
A: Current version is for demo/testing only. For real payments, integrate with Stripe, PayPal, or local Rwanda payment gateway.

**Q: Can I add more features later?**
A: Yes! All code is modular and maintainable. Easy to add email notifications, inventory management, etc.
